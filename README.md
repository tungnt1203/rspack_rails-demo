# rspack_rails demo

A small Rails 8 app built with [rspack_rails](https://github.com/tungnt1203/rspack_rails): Stimulus controllers in TypeScript, Tailwind CSS v4, code splitting and a second entry point, all with hot module replacement under `bin/dev`.

Use it to see what an rspack_rails app looks like, or as a playground before adding the gem to your own app.

## Run it

You need Ruby 3.2+ and Node.js 20.19+ or 22.12+.

```bash
git clone https://github.com/tungnt1203/rspack_rails-demo.git
cd rspack_rails-demo
bundle install
npm install
bin/dev
```

Open http://localhost:3000.

## Try hot reloading

With `bin/dev` running and the page open:

1. Click **Click me** a few times, then edit `app/javascript/controllers/counter_controller.ts` (change `"click"` to `"tap"`). The label updates and the count stays, because the page does not reload.
2. Add `bg-amber-100` to a card in `app/views/pages/home.html.erb`. Tailwind generates the class and the dev server applies the new CSS.
3. Edit `app/javascript/application.css`. The change shows up without a reload.
4. Click **Load primes.ts** with the network tab open: the chunk is fetched only then.

## What to look at

| File | What it shows |
|---|---|
| [`app/javascript/application.ts`](app/javascript/application.ts) | The main entry point, in TypeScript, using a `@/` path alias from `tsconfig.json` |
| [`app/javascript/controllers/`](app/javascript/controllers) | Stimulus controllers in TypeScript, registered by `autoload.js` with no manifest |
| [`app/javascript/controllers/lazy_controller.ts`](app/javascript/controllers/lazy_controller.ts) | `import()` building a separate chunk |
| [`app/javascript/application.css`](app/javascript/application.css) | Tailwind CSS v4 and an SVG referenced with `url()` |
| [`app/javascript/entrypoints/admin.ts`](app/javascript/entrypoints/admin.ts) | A second bundle, loaded by [`layouts/admin.html.erb`](app/views/layouts/admin.html.erb) |
| [`app/javascript/entrypoints/print.css`](app/javascript/entrypoints/print.css) | A stylesheet-only entry point, linked with `media: "print"` |
| [`app/views/layouts/application.html.erb`](app/views/layouts/application.html.erb) | `rspack_javascript_tag` and `rspack_stylesheet_tag` |
| [`rspack.config.mjs`](rspack.config.mjs) | The config generated by `rspack:install` |

## How it was made

Each step is its own commit, so `git log -p` shows exactly what every installer changed:

```bash
rails new rspack_rails-demo --skip-javascript   # plus --skip-* for the parts the demo does not use
bundle add rspack_rails
bin/rails rspack:install
bin/rails rspack:install:stimulus
bin/rails rspack:install:typescript
bin/rails rspack:install:tailwind
```

The demo pages come after that.

## Other commands

```bash
npm run typecheck          # type-check the TypeScript
bin/rails rspack:doctor    # check the setup
bin/rails rspack:analyze   # bundle report in tmp/rsdoctor/rsdoctor-report.html
RAILS_ENV=production SECRET_KEY_BASE_DUMMY=1 bin/rails assets:precompile
```
